## 三、KPI 数据

### 3.1 KPI 卡片汇总数据 (KpiSummary)

| 字段名       | 类型    | 说明                       | 示例                 |
| ------------ | ------- | -------------------------- | -------------------- |
| projectId    | string  | 项目ID（可选，全局时为空） | "PRJ-2025-001"       |
| kpiType      | enum    | KPI类型                    | "taskCompletionRate" |
| kpiTitle     | string  | KPI标题                    | "任务完成率"         |
| currentValue | string  | 当前值                     | "78%"                |
| delta        | string  | 变化值                     | "+2%"                |
| isUp         | boolean | 是否上升                   | true                 |
| compareMode  | enum    | 比较模式 (plan/mom)        | "plan"               |

**KPI类型枚举**：

- `fundArrivalRate` - 资金到账率
- `taskCompletionRate` - 任务完成率
- `projectExpenditure` - 项目支出金额
- `personnelHealth` - 人员健康度
- `overdueTaskRate` - 逾期任务率

### 3.2 KPI 趋势曲线数据 (KpiTrendSeries)

> 每个 KPI 的 60 天计划与实际趋势曲线

| 字段名      | 类型   | 说明         | 示例                 |
| ----------- | ------ | ------------ | -------------------- |
| projectId   | string | 项目ID       | "PRJ-2025-001"       |
| kpiType     | string | KPI类型      | "taskCompletionRate" |
| date        | date   | 日期         | "2025-12-11"         |
| planValue   | number | 计划值 (0-1) | 0.78                 |
| actualValue | number | 实际值 (0-1) | 0.76                 |

## 十四、数据关联说明

### 14.1 进度兑现指数计算规则

```
进度兑现指数 = Σ(管理层指标标准化评分 × 权重占比)

权重配置：
- 开工准点率: 10%
- 完工准点率: 15%
- 关键里程碑达成率: 35%
- 平均任务工期比: 15%
- 逾期恢复时长: 10%
- 逾期积压率: 7.5%
- 逾期解决率: 7.5%
```

### 14.2 人员健康度判定规则

```
- 挂名项目 > 3 个：判定为风险人员
- 健康度评分 = 正常人数 / 总人数 × 100
- 健康状态：
  - ≥80%: 良好
  - ≥60%: 预警
  - <60%: 危险
```
