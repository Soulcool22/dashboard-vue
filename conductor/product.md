# 初始概念

这是一个基于 Vue 3 + Element Plus 的单页数据看板项目，用于可视化展示工程项目的关键绩效指标（KPI），包括资金到位、任务完成情况、人员健康、项目支出等维度。

# 产品定义

## 产品愿景

打造一个专业、直观的项目管理看板，帮助项目管理团队和领导层实时掌握项目动态，通过数据驱动决策，提升项目执行效率和资金管理透明度。

## 目标用户

- **项目经理**：需要监控每日任务进度、资源分配和潜在风险。
- **领导层**：关注宏观 KPI、财务健康状况以及各区域项目的对比表现。

## 核心目标

- **实时监控**：提供任务进度、逾期任务的实时预警，确保项目按计划推进。
- **财务透明化**：清晰展示资金到账、项目支出及预算使用情况，识别资金风险。
- **区域对比分析**：支持不同区域、不同项目间的横向对比，帮助管理者识别表现优异或存在瓶颈的区域。

## 关键功能

- **任务完成率与预警系统**：自动识别逾期任务，展示整体进度曲线。
- **资金管理模块**：收支对比分析，资金到位率监控。
- **人员健康与安全监控**：实时展示现场人员状态，确保安全管理闭环。

## 数据策略

- **混合驱动模式**：初期通过本地 CSV/Excel 文件进行数据驱动和快速验证，代码层面严格预留 API 接口定义，确保后续能无缝平滑迁移至真实后台 API。
